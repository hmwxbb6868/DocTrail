# DocTrail 错误码表

| Result.code | HTTP | 含义 | 当前阶段 |
| ---: | ---: | --- | --- |
| 1 | 2xx | 成功 | 已使用 |
| 1001 | 401 | 登录凭据或 access token 无效 | 阶段 2 实现 |
| 1002 | 401 | access/refresh token 已过期或被吊销 | 阶段 2 实现 |
| 1003 | 403 | 已认证但无权访问资源 | 阶段 2 实现；阶段 3.5 用于消息反馈 |
| 1004 | 409 | 用户名或其他唯一业务键冲突 | 阶段 2 实现 |
| 2001 | 404 | 业务资源不存在 | 阶段 3 起实现；阶段 3.5 用于消息反馈 |
| 2002 | 409 | 资源状态不允许当前操作 | 阶段 3 起实现；阶段 3.5 用于消息反馈 |
| 3001 | 502 | Python AI 服务不可达、未就绪或远端服务不可用 | 阶段 5 起冻结 |
| 3002 | 504 | Java → Python 调用或模型读取超时 | 阶段 5 起冻结 |
| 3003 | 502 | Python 响应可解析但违反冻结契约（含 FastAPI 422、run/trace 不一致） | 阶段 5 起冻结 |
| 4000 | 400 | 请求参数、JSON 或请求头不合法 | 已使用；阶段 3.5 用于消息反馈 |
| 4001 | 400 | 验证码无效、过期或已被消费 | 阶段 2.5 |
| 4002 | 413 | 文件或请求体超过允许大小 | 阶段 4 实现 |
| 4003 | 415 | 服务端文件类型探测失败或文件类型不在白名单 | 阶段 4 实现 |
| 4290 | 429 | 请求超过限流规则 | 当前路线不排期 |
| 5000 | 500 | 快照收尾失败、900 秒 RUNNING 超时回收或其他内部服务错误 | 阶段 5/6 使用 |
| 5010 | 501 | 当前阶段未实现或已取消的功能 | stream、未启用认证功能 |

错误响应仍使用 `Result`：`data` 为 `null`，`msg` 是不包含堆栈、密钥和内部地址的用户可读摘要。Python 内部接口暂时使用 FastAPI 的 `detail` 错误体；Java 必须将其转换成上述公共错误，不能原样泄漏给浏览器。
